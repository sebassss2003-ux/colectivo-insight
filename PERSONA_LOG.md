# PERSONA TEST — COLECTIVO INSIGHT

## Synthetic User

**Name:** José  
**Age:** 52  
**Role:** Colectivo driver  
**Route:** Ruta 1 — Metro Indios Verdes → Metro Universidad

### Context

José uses WhatsApp every day but does not normally use new apps. 
He needs to report operational exceptions quickly and does not want to lose
time while working.

He is also concerned that information generated by drivers could be used
for surveillance or punishment.

---

# Test Tasks

## Task 1 — Find the pilot route

**Expected:** Identify the route being tested.

**Result:** PASS

José quickly identified:

> Ruta 1 — Metro Indios Verdes → Metro Universidad

The map and route information made the pilot route understandable.

**Confusion:** None.

---

## Task 2 — Report a closed street

José was asked to create the following report:

- Type: Calle cerrada
- Location: Av. Insurgentes
- Description: Calle cerrada por obras
- Expiration: Hoy

**Result:** PASS

José completed the form without assistance.

The available report types were understandable and the form did not require
unnecessary information.

**Confusion:** None important.

---

## Task 3 — Identify the AI system

**Expected:** Understand that the AI output is simulated and requires human review.

**Result:** PASS

José found the "IA SIMULADA" label and understood that the system does not
automatically decide whether a report is true.

**Confusion:** None.

---

## Task 4 — Remove the demo report

**Expected:** Find the option to remove the saved demonstration report.

**Result:** PASS

José found the "Limpiar demo" button and understood its purpose.

**Confusion:** None.

---

## Task 5 — Understand telemetry

**Expected:** Find and interact with the simulated telemetry.

José opened the telemetry section and selected:

> Simular actualización de telemetría

The speed, status and position changed.

**Result:** PASS with minor confusion.

### Confusion observed

At first, José interpreted the speed and position information as possible
driver tracking.

After reading the surrounding explanation, he understood that the data was
simulated and did not represent permanent driver tracking.

---

# Main Finding

The main usability issue was not task completion.

The issue was **interpretation of the telemetry section**.

The presence of speed and position can initially look like a surveillance
feature, even though the interface explains that the data is simulated.

---

# Fix

The telemetry section should make the limitation even more visible.

Proposed message:

> **DATOS SIMULADOS — NO ES SEGUIMIENTO DEL CONDUCTOR**

This message should appear directly in the telemetry card instead of relying
only on the paragraph below the section title.

---

# Test Conclusion

José completed the main product tasks without assistance:

- Found the pilot route.
- Created an operational exception report.
- Identified the simulated AI.
- Understood the verification requirement.
- Found the demo reset option.
- Interacted with simulated telemetry.

The main improvement identified was making the non-surveillance nature of the
telemetry immediately visible.

The test supports continuing with a narrow pilot focused on operational
exceptions rather than driver monitoring or worker profiling.
